Markdown Bold Fixer
プライバシーポリシー

最終更新日：2026年10月11日

Markdown Bold Fixerは、ChatGPT・ClaudeのAI回答内で、太字にならずに残ったMarkdownの太字記号を補正するChrome拡張機能です。

回答テキストの取り扱い

補正を有効にしたサイトでは、ページ上のAI回答のテキストを読み取り、補正が必要な箇所の画面表示を変更します。この処理は利用者のブラウザ内だけで行います。

会話内容をファイルやストレージに保存する機能はありません。会話内容、入力内容、アカウント情報を、開発者、外部サーバー、第三者へ送信する機能もありません。ユーザーの発言や入力欄は補正しません。

保存する設定

ChatGPTとClaudeそれぞれの補正をオン／オフする設定を、Chromeのchrome.storage.localに保存します。この設定は、次回以降も同じ状態で利用するために使います。

会話内容、閲覧履歴、ページのタイトルやURLを設定として記録することはありません。

権限と動作するサイト

storage権限は、オン／オフ設定の保存に使います。ページへのアクセスはchatgpt.comとclaude.aiに限定し、AI回答の表示補正に使います。

外部通信・第三者への提供

拡張は外部API、広告、アクセス解析、追跡ツールを使用しません。リモートコードの取得や実行も行いません。拡張が扱う回答テキストや設定を販売したり、第三者に提供したりしません。

ChatGPT・Claude自体が行う通信やデータ処理は、それぞれのサービスの規約とプライバシーポリシーに従います。

利用者による操作

ツールバーのポップアップで、サイトごとの補正を停止できます。補正をオフにしてページを再読み込みすると、補正前の表示に戻ります。拡張を削除すると、Chromeが管理する拡張のローカル設定も削除されます。

利用目的

回答テキストと設定は、太字表示の補正という単一目的だけに使用します。Chrome Web StoreのユーザーデータポリシーとLimited Use要件に沿って取り扱います。
